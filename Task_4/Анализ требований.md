# Анализ требований к функционалу продажи ОСАГО онлайн

#### Функциональные требования
| №   | Участники                       | Описание                                                                                                                                                                                                                                      |
|:----|:--------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FR1 | Клиент, Web-приложение          | Клиент заполняет заявку с информацией о своем автомобиле. В ответ на заявку клиент на экране видит предложения от каждой страховой, подходящей по условиям заявки.                                                                            |
| FR2 | Сервис InsureTech, API СК       | Сервис запрашивает у всех доступных страховых компаний предложения с условиями страхования под заявку клиента                                                                                                                                 | 
| FR3 | Сервис osago-aggregator, API СК | 1) Сервис osago-aggregator создает заявку на ОСАГО с помощью REST API на эндпоинт API СК.<br/>2) Сервис osago-aggregator опрашивает API СК, чтобы получить предложение по заявке.<br/>3) Сервис osago-aggregator передает решение в core-app. |
| FR4 | Сервис core-app                 | Реализует остальной функционал, связанный с оформлением ОСАГО.                                                                                                                                                                                |

#### Нефункциональные требования
| №    | Описание                                                                                                          |
|:-----|:------------------------------------------------------------------------------------------------------------------|
| NFR1 | Предложения СК по заяявке пользователя должны отображаться на экране пользователя по мере получения ответа от СК. |
| NFR2 | Максимальное время ожидания решения от страховой компании - 60 секунд. |
| NFR3 | Бизнес предполагает, что в пик нагрузки количество одновременных пользователей, создающих заявку на ОСАГО, может достигать 2,5 тысячи человек. |
| NFR4 | Решение должно работать корректно при условии, что сервисы задеплоены в нескольких экземплярах. |
